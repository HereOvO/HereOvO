## 嵌入式系统与机器人

我是河海大学本科生，主要做 STM32、ESP32、电机控制、远程升级和小型机器人平台相关项目。

我关注系统里那些演示结束后仍然必须稳定工作的部分：

- 启动流程与固件升级路径
- 电机控制与实时 I/O
- 嵌入式设备之间的通信
- 调试、烧录和部署工具
