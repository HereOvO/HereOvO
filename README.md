## Embedded systems & robotics

I am an undergraduate student at Hohai University, building firmware and hardware projects around STM32, ESP32, motor control, and small robotic platforms.

I like the parts of a system that have to keep working after the demo:

- boot flows and firmware upgrade paths
- motor control and real-time I/O
- communication between embedded devices
- practical tools for debugging and deployment
